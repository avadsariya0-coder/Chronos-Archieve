# Chronos-Archieve
The structure consists of a Monolith made from four-sided tapered CylinderGeometry, an Oracle Eye made from nested TorusGeometry rings with a transparent SphereGeometry for the center as it rotates, a Data Scythe made from an elongated cylinder with a cross section wireframe torus arc, and a series of BoxGeometry objects laid out in a spiral fashion as a result of the trigonometric sine and cosine functions, covering a flat PlaneGeometry surface. All of these components use the same 1024x1024 Procedural Canvas Texture created via code that contains, on a dark metallic background, a grid of orange lines resembling a circuit and an opaque white block dashed line for each individual object. By placing this procedural canvas texture into the color map, roughnessMap, and emissive map slots for the material simultaneously, the code produces a realistic variation of the light reflecting off each of the panel lines and uses the white data dashes in the alpha map as an illumination mask, emitting a bright pulse of amber light only from the rune fragments. The base plates of each structure remain dark.
